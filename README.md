# Python Student Records Management

## About the Project
This is a beginner-friendly Python project that demonstrates how to store and manage student records using text files and CSV files.

The program stores student details such as roll number, name, department, and marks. It also demonstrates how to use tuples and Python's built-in CSV module.

## Features
- Stores student information using Python dictionaries.
- Demonstrates tuple usage for course details.
- Writes student records to a text file (`students.txt`).
- Exports student records to a CSV file (`students.csv`).
- Reads and displays student records from a CSV file.

## Technologies Used
- Python
- CSV module
- File handling
- Dictionaries and tuples

## Project Files
- `main.py` — Main Python program.
- `students.txt` — Student records stored as text.
- `students.csv` — Student records stored in CSV format.
- `README.md` — Project documentation.

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open a terminal in the project folder.
5. Run the following command:

```bash
python main.py
```

The program displays the course details and student records. It also creates or updates the text and CSV files.

## Concepts Learned
- Python lists and dictionaries
- Tuples
- File handling using `open()`
- Reading and writing text files
- CSV file handling using `csv.DictWriter` and `csv.DictReader`

## Learning Purpose
This project was created for practicing basic Python programming and file handling concepts.
